# JWT Authentication with Spring Security

JWT authentication is one of the most commonly used mechanisms for securing modern REST APIs.

## Why JWT?

JWT allows stateless authentication by storing claims inside a signed token.

### Benefits

- Stateless
- Scalable
- API friendly

## Spring Security Flow

1. User logs in
2. JWT generated
3. Token returned
4. Client sends token
5. Filter validates token

## Conclusion

JWT works well for modern backend systems when implemented correctly.
