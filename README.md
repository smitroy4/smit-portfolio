# Smit Roy Portfolio

A modern developer portfolio built to showcase projects, technical blogs, open-source contributions, and learning resources.

Designed with a documentation-inspired interface and focused on performance, accessibility, and developer experience.

## Features

* Responsive Design
* Light & Dark Theme
* Project Showcase
* Markdown-Powered Blog System
* Technical Resources Section
* Contact Form Integration
* Reading Progress Indicator
* Code Snippet Copy Button
* SEO Friendly Structure
* React Router Navigation
* Vercel Ready Deployment

## Running Locally

Clone the repository:

```bash
git clone <repository-url>
cd smit-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Environment Variables

Create a `.env` file in the project root:

```env
VITE_WEB3FORMS_ACCESS_KEY=your_access_key
```
